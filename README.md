# 🎨 Design Patterns in Python – Complete Collection  
### *Creational · Structural · Behavioral*

Este repositorio contiene una colección completa de **Patrones de Diseño implementados en Python**, acompañados de explicaciones claras, ejemplos prácticos y versiones avanzadas listas para usar en proyectos reales.

Los Patrones de Diseño son soluciones probadas a problemas comunes de arquitectura, diseño de software y organización de código.  
Su objetivo es ayudarte a escribir:

✔ Código **más limpio**  
✔ Código **más reutilizable**  
✔ Código **más escalable**  
✔ Código **más fácil de mantener**  
✔ Código **más profesional**

Este repositorio está pensado para:

- Estudiantes  
- Desarrolladores intermedios  
- Arquitectos de software  
- Programadores que quieren mejorar su forma de pensar  
- Implementaciones reales en backend, frontend, videojuegos, IoT, etc.

---

## 🧱 Clasificación Oficial de Patrones de Diseño

Este repositorio está organizado siguiendo la clasificación de la *Gang of Four (GoF)*.

---

# 🌱 1. Patrones Creacionales  
Patrones que ayudan a **crear objetos** sin acoplar el código a clases concretas.

| Patrón | Propósito | Archivo |
|--------|-----------|---------|
| **Factory Method** | Delega la creación de objetos a subclases | `factory_method.py` |
| **Abstract Factory** | Crea familias completas de objetos relacionados | `abstract_factory.py` |
| **Builder** | Construye objetos complejos paso a paso | `builder.py` |
| **Prototype** | Clona objetos sin acoplar al código | `prototype.py` |

---

# 🧱 2. Patrones Estructurales  
Patrones que ayudan a **organizar clases y objetos**, agregando flexibilidad a grandes sistemas.

| Patrón | Propósito | Archivo |
|--------|-----------|---------|
| **Adapter** | Hace compatibles interfaces incompatibles | `adapter.py` |
| **Bridge** | Separa abstracción de implementación | `bridge.py` |
| **Composite** | Estructuras jerárquicas tipo árbol | `composite.py` |
| **Decorator** | Añade funcionalidades dinámicamente | `decorator.py` |
| **Facade** | Simplifica sistemas complejos | `facade.py` |
| **Flyweight** | Optimiza memoria compartiendo objetos pesados | `flyweight.py` |
| **Proxy** | Controla el acceso a un objeto mediante capas | `proxy.py` |

# ☑️  3. Patrones de Comportamiento
Patrones que ayudan a **el comportamiento**, Definiendo como los objetos se comunican y colaboran sin acoplarse entre sí.
| Patrón | Propósito | Archivo |
|--------|-----------|---------|
| **ChangeOfResposibity(CoR)** | Controla el flujo de una solicitud | `change_of_responsibity.py` |
| **State** | El estado actual define el comportamiento | `state.py` |
| **TemplateMethod** | Controla el flujo fijo y los detalles varían | `template_method.py` |
| **Observer** | Encapsula una acción como un objeto para desacoplar quién la solicita de quién la ejecuta. | `observer.py` |
